## Key API Reminders

### FoShape2D vs FoShape3D

| Property | FoShape2D | FoShape3D |
|----------|-----------|-----------|
| Position | `PinX`, `PinY` (int) | `Transform.Position` (Vector3) |
| Move | `MoveTo(int x, int y)` | `Transform.Position = new Vector3(...)` |
| Size | `Width`, `Height` (int) | `Width`, `Height`, `Depth` (double) |
| Color | `Color` (string) | `Color` (string) |
| Constructor | `new FoShape2D(int w, int h, string color)` | `new FoShape3D(string name)` then `.CreateBox(...)` |

### RenderContext Usage

```csharp
// DON'T use constructors directly from test pages
```
